# マネジメントゲーム（製造業・ジュニアルール）

製造業の会社を経営して決算を競うマネジメントゲームを、ゼミ用にブラウザで遊べるようにしたものです。

**遊ぶ：https://jtoxyz.github.io/mg-game/** （スマホ・PCのブラウザで開くだけ。インストール不要）

## 遊び方

| モード | 内容 |
|---|---|
| CPUと対戦 | 自分1社＋CPU 1〜5社。CPUは「堅実・積極・バランス」の3タイプ |
| 1台を回して対戦 | 1台のPC・タブレットを順番に操作。入札は目隠し画面を挟んで1人ずつ入力 |
| オンライン | ホストが「部屋を作る」→ 4文字の部屋コードを共有 → 参加者は「部屋に参加」。空いた枠はCPUで埋められる |

- 期数（1〜5期）と、1期あたりの手番数（1人6〜20回）を開始前に選べます。
- 現金出納帳・原価計算・変動損益（MQ会計）・B/S・順位表は自動で作られます（「決算書」ボタン）。
- ゲームはその端末のブラウザに自動保存され、タイトルの「続きから」で再開できます。

## 自分のPCで起動

上のURLで遊べますが、手元で動かす場合はファイルを置いたフォルダで静的サーバーを立てて開きます。

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます。CPU対戦と「1台を回して対戦」は `index.html` を直接開いても遊べます。

オンライン対戦は、全員が上のURLを開いて、ホストが作った部屋コードで参加します。

## オンライン対戦の仕組み

- ホストの端末がゲームを進め、参加者は操作を送って結果を受け取ります。ホストのタブを閉じるとゲームが止まります（ホストが「続きから」で同じ部屋コードを開き直せば、参加者は再接続できます）。
- 通信は標準で PeerJS（WebRTC、設定不要）を使います。学内Wi-Fiなどでつながらない場合は、`js/config.js` に Supabase プロジェクトの URL と anon key を入れると Supabase Realtime 経由になります。
- 通信が切れて戻れない参加者がいるときは、ホストの「メニュー」からその会社をCPUに交代できます。

## ルールの調整

`js/data.js` に数値がまとまっています。

- マーケット（材料単価・上限価格・マーケットボリューム）、各単価、期末費用単価表、借入条件、税率
- `RISK_RATIO`：意思決定カードのうち「リスクカードを引く」の割合（標準 0.2 ＝ 5枚に1枚）
- `RISK_CARDS`：リスクカード。`weight` が枚数、効果は `js/engine.js` の `applyRisk()` にあります。
  - ゼミのカード：ワーカー退職・セールスマン退職（各退職費5、一般管理費）、倉庫火災発生（材料すべて焼失、保険で1個8）、社長が倒れた（1回休み）、逆回り、窃盗（製品すべて盗難）、工場の機械が壊れる（機械すべて廃棄、帳簿価額を特別損失に）
  - こちらで作ったカード：製造ミス、材料の特別購入、独占販売、研究開発の成功・失敗、広告が大ヒット、クレーム発生
- `RETIRE_FEE`：退職費（標準 5）

## デジタル版で決めたこと（ルール表に書かれていない部分）

- マーケットの材料は毎期首にマーケットボリュームまで補充。材料を買うと空きができ、空きの数まで製品を売れる。
- 期首・期末の支払いで現金が足りないときは自動で緊急借入（10単位）。
- 入札は競争価格（入札価格 −2（親）−2×青チップ）の安い順。子は1人あたり親が出した個数まで応札でき、マーケットの空きの数まで上位から売れる（例：空き6で4人が2個ずつなら1〜3位が売れる）。
- 親と応札した子の全員の競争価格が同じなら親の負け（順位は最後）。子が2人以上いて空きに全員分が入らないときは、子だけで価格を出し直す（個数は最初のまま・辞退も可）。
- 一部だけ同じ競争価格のときは、青チップの多い順、親の順。再入札でも同じならジャンケンの代わりにランダムで決定。
- リスクカードはクリックするまで表示し、その間CPUは止まる。
- 平均単価は四捨五入、売上原価などは差額で求める（シートと同じ手順）。
- 法人税等は50%。前期繰越利益剰余金がマイナスなら通算後に計算し、翌期首に納付。

## ファイル構成

```
index.html        画面の土台
css/style.css     見た目
js/data.js        ルールの数値・リスクカード
js/engine.js      ルール処理と会計（状態 + アクション）
js/ai.js          CPUの思考
js/net.js         オンライン通信（PeerJS / Supabase）
js/ui.js          画面描画
js/app.js         画面遷移・入力・保存
```
